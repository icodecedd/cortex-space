# 📂 Onboarding & Mode Selection

## 📌 Overview
The Onboarding module manages the initial user experience upon application launch. It handles the splash screen sequence and the critical choice between **Normal Mode** (Manual Control) and **Agents Mode** (AI-Assisted).

## 🏗️ Architecture
- **Entry Points**: 
  - `src/components/screens/SplashScreen.tsx`
  - `src/components/screens/ModeSelectorScreen.tsx`
- **State Management**: `src/lib/store.ts` (Persists `startup.lastMode`)
- **Mode Definition**: `src/types.ts` (`Mode = 'normal' | 'agents'`)

## 🔄 Data Flow
1.  **Launch**: `App.tsx` determines if it should show the `SplashScreen`.
2.  **Detection**: If no active workspace is found, the system presents the `ModeSelectorScreen`.
3.  **Selection**: User chooses a mode; the choice is persisted to the local store via `setSetting`.
4.  **Transition**: The application state shifts to `setup`, passing the selected mode to `SetupView`.

## 🛠️ Key Components
| Component | Responsibility |
| :--- | :--- |
| `SplashScreen` | Animated entry point that verifies system readiness. |
| `ModeSelectorScreen` | High-impact UI for selecting the operational workflow. |
| `ConfirmModeChangeDialog` | Guardrail for switching modes while a workspace is active. |

## 🧪 Verification & Testing
- **Key Scenarios**:
  - Closing and reopening the app restores the last selected mode if configured.
  - Selecting "Agents Mode" correctly initializes the `SetupView` with agent-specific fields.
