# 📂 Theming & Appearance Engine

## 📌 Overview
Cortex Space features a comprehensive theming engine that synchronizes the React UI colors with the underlying Xterm.js terminal instances. It supports custom themes, system dark mode detection, and real-time font scaling.

## 🏗️ Architecture
- **Entry Points**: 
  - `src/hooks/useTheme.ts` (Global Theme Logic)
  - `src/hooks/useColorScheme.ts` (System Sync)
- **CSS Architecture**: CSS Variables defined in `src/index.css` and dynamically injected.
- **Terminal Sync**: `XtermTerminal.tsx` listens for theme changes to update its internal palette.

## 🔄 Data Flow
1.  **Setting Update**: User changes theme in `SettingsDialog`.
2.  **Broadcasting**: `useTheme` updates global CSS variables and local storage.
3.  **Propagation**: 
    - React components re-render based on theme variables.
    - Active terminal sessions update their `options.theme` object via the `XtermTerminal` hook.
4.  **Persistence**: Settings are saved to `cortex_appearance_settings`.

## 🛠️ Key Components
| Component | Responsibility |
| :--- | :--- |
| `useTheme` | Manages the primary theme palette and CSS injection. |
| `useColorScheme` | Detects OS-level light/dark mode changes. |
| `App.css` | Defines the semantic variable mappings (e.g., `--accent-primary`). |

## 🧪 Verification & Testing
- **Key Scenarios**:
  - Switching to "Midnight" theme updates both the sidebar and the terminal background.
  - Changing "UI Font Scale" adjusts the entire interface without breaking layouts.
