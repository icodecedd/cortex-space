# 📂 Workspace Setup Module

## 📌 Overview
The Setup module provides a multi-step wizard interface for defining a new terminal workspace. It handles directory selection, layout topology configuration, and process (pane) initialization.

## 🏗️ Architecture
- **Entry Point**: `src/components/SetupView.tsx`
- **Primary Hooks**: 
  - `src/hooks/useSetupPanes.ts`: Manages layout state and pane configurations.
  - `src/hooks/useWorkspaceDirectory.ts`: Handles filesystem navigation via Tauri.
- **Dependencies**: 
  - `framer-motion`: For step transitions.
  - `lucide-react`: For iconography.
  - `tauri-api`: For directory browsing.

## 🔄 Data Flow
1.  **Mounting**: User selects a root directory (Step 1).
2.  **Topology**: User chooses a grid layout (Step 1).
3.  **Command Matrix**: User defines execution hooks for each pane (Step 2).
4.  **Verification**: System derives semantic labels and validates paths (Step 3).
5.  **Finalization**: Configuration object is passed to `onLaunch` to initialize `SpaceView`.

## 🛠️ Key Components
| Component | Responsibility |
| :--- | :--- |
| `src/components/setup/steps/StepWorkspace.tsx` | Handles mounting path and grid selection. |
| `src/components/setup/steps/StepConfigure.tsx` | Manages the command matrix and agent assignments. |
| `src/components/setup/ui-parts/PaneConfigCard.tsx` | Individual pane configuration unit with automated labeling. |
| `src/components/setup/ui-parts/LayoutSelector.tsx` | Visual grid topology picker. |

## 🧪 Verification & Testing
- **Key Scenarios**:
  - Selecting an invalid directory triggers a toast error.
  - Changing layout preserves existing pane commands where possible.
  - Smart labeling derives "Dev" from `npm run dev`.
