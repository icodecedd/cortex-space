# 📂 Cortex Library & Snippets

## 📌 Overview
The Cortex Library is the central registry for user assets, including command snippets, AI agent identities, and workspace templates. It handles persistence and global availability of these assets across all modes.

## 🏗️ Architecture
- **Entry Point**: `src/components/dialogs/CortexLibraryDialog.tsx`
- **Primary Hooks**: 
  - `src/hooks/useSnippets.ts`: CRUD operations for command snippets.
  - `src/hooks/useSpaceTemplates.ts`: Management of reusable workspace configurations.
- **Persistence**: `src/lib/store.ts` (Tauri-plugin-store)

## 🔄 Data Flow
1.  **Ingestion**: Users capture a current workspace as a template or manually enter a snippet.
2.  **Storage**: Assets are serialized and saved to the local filesystem via the `store` abstraction.
3.  **Consumption**: `SetupView` or `TerminalPane` queries the hooks to populate "Quick-Pick" menus or auto-complete lists.

## 🛠️ Key Components
| Component | Responsibility |
| :--- | :--- |
| `src/components/dialogs/cortex-library/tabs/` | Segmented views for Snippets, Agents, and Templates. |
| `src/components/ui/combobox.tsx` | Reusable search-and-select interface for library assets. |
| `src/components/dialogs/TemplateLibraryDialog.tsx` | Dedicated view for managing space architectures. |

## 🧪 Verification & Testing
- **Key Scenarios**:
  - Adding a snippet in the library makes it instantly available in the Setup configuration.
  - Deleting a template removes it from the "Quick Launch" palette.
