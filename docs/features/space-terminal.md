# 📂 Terminal & Space System

## 📌 Overview
The Space module manages the runtime environment of the workspace. It coordinates multiple terminal panes, handles focus management, and provides the bridge to the backend PTY processes.

## 🏗️ Architecture
- **Entry Point**: `src/components/SpaceView.tsx`
- **Session Manager**: `src/lib/terminalSessionManager.ts`
- **Primary Hook**: `src/hooks/usePty.ts`
- **UI Engine**: `src/components/XtermTerminal.tsx`

## 🔄 Data Flow
1.  **Spawn**: `usePty` requests a new shell process from the Tauri backend.
2.  **Stream**: `terminalSessionManager` listens for binary output and broadcasts it via event emitters.
3.  **Render**: `XtermTerminal` consumes the stream and renders it to the GPU-accelerated canvas.
4.  **Input**: Key events from Xterm are sent back through `usePty` to the underlying process.

## 🛠️ Key Components
| Component | Responsibility |
| :--- | :--- |
| `src/components/TerminalPane.tsx` | Layout wrapper with header, controls, and focus management. |
| `src/components/XtermTerminal.tsx` | Low-level xterm.js integration and ANSI sequence handling. |
| `src/components/space/SpaceStatusBar.tsx` | Global health and status indicator for active sessions. |
