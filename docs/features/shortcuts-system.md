# 📂 Keyboard Shortcuts & Hotkeys

## 📌 Overview
The Shortcut system provides a centralized, configurable way to manage application-wide hotkeys. It bridges the gap between focused terminal panes (which intercept input) and global app actions.

## 🏗️ Architecture
- **Entry Points**: 
  - `src/hooks/useAppShortcuts.ts` (Global Listener)
  - `src/lib/shortcut-utils.ts` (Parsing & Matching)
- **UI Components**: `src/components/dialogs/KeyboardShortcutsDialog.tsx`
- **Interception Logic**: `src/components/XtermTerminal.tsx` explicitly checks for global shortcuts to allow them to "bubble up" past the terminal input.

## 🔄 Data Flow
1.  **Input**: User presses a key combination.
2.  **Interception**: `XtermTerminal` (if focused) checks `isGlobalShortcut`.
3.  **Handoff**: If global, the event is allowed to reach the window-level listener in `useAppShortcuts`.
4.  **Execution**: The matched action (e.g., Open Settings, New Space) is executed.

## 🛠️ Key Components
| Component | Responsibility |
| :--- | :--- |
| `useAppShortcuts` | The primary listener that maps keys to state-changing functions. |
| `shortcut-utils` | Normalizes keyboard events into strings for comparison (e.g., `ctrl+shift+p`). |
| `Kbd` | UI component for standardized shortcut rendering. |

## 🧪 Verification & Testing
- **Key Scenarios**:
  - `Ctrl + ,` opens Settings even when a terminal is actively receiving input.
  - `Alt + ArrowKeys` successfully shifts focus between terminal panes.
